# 首页论文标题溢出修复设计

## 背景

首页总览表格的标题单元格依次渲染可选语义分数、收藏按钮和中英文标题组。当前标题组使用行内布局与 `max-width: 100%`，但该宽度没有扣除前置元素。标题很长时，整个标题组会换到新的行内行并从单元格左侧开始，造成标题向左突出、与其他行错位。

## 目标

- 所有标题都从收藏按钮之后开始，不再因长度变化而向左突出。
- 英文标题和中文标题各保持一行，超出可用宽度时显示省略号。
- 保持当前紧凑行高、双语层级、表格列宽及桌面和窄屏工作流。
- 保留现有点击、收藏、语义分数和完整标题数据，不修改后端接口或数据库。

## 方案

在 `public/app.js` 的首页标题单元格中增加一个仅负责布局的内部容器。该容器包含可选语义分数、收藏按钮和现有 `.paper-title-stack`，不改变这些元素的内容、事件或条件渲染。

在 `public/style.css` 中将内部容器设为横向 Flex 布局：

- 内部容器占满标题单元格，并使用 `min-width: 0`。
- 语义分数和收藏按钮保持固定宽度，不参与压缩。
- `.paper-title-stack` 使用纵向 Flex、`flex: 1` 与 `min-width: 0`，只占用前置元素之后的剩余空间。
- 英文主标题和中文副标题均使用 `white-space: nowrap`、`overflow: hidden` 和 `text-overflow: ellipsis`。
- 删除标题组依赖 `max-width: 100%` 的行内宽度计算，避免整个标题组换行。

该结构能自然处理语义分数存在或缺失、收藏状态变化以及表格宽度变化，不需要维护易失效的固定宽度减法。

## 边界与兼容性

- 没有中文标题时，只渲染英文标题，布局仍占用相同的剩余宽度。
- 有语义分数时，标题从分数和收藏按钮之后开始；没有语义分数时，空间自动归还标题。
- 超长单词也必须被容器裁切，不能撑宽单元格或覆盖会议标签列。
- 本次不允许英文标题扩展为两行，以保持总览列表的扫描密度。
- 本次不改动阅读页、管理页、复习页或其他标题展示组件。

## 验证

- 使用普通标题和截图中的超长标题检查起始位置、行高和省略号。
- 分别验证有无中文标题、有无语义分数以及收藏和未收藏状态。
- 在桌面宽度和项目现有窄屏断点下确认标题不会覆盖编号、徽标或会议列。
- 运行现有自动化测试，确认标题渲染调整未影响数据和交互行为。
- 使用浏览器截图对比修改前后页面，检查浅色和深色主题下的对齐与可读性。

## 非目标

- 不调整标题字号、配色、翻译内容或排序规则。
- 不增加新的提示框、弹窗或标题编辑能力。
- 不重构首页表格之外的前端结构。
